# Model Context Protocol (MCP)

Source:
Model Context Protocol Official Documentation

Reference:
https://modelcontextprotocol.io/


## Overview

Model Context Protocol (MCP) is an open protocol that enables applications to provide context, tools, and resources to AI models in a standardized way.

It defines a common interface between AI applications and external systems.


## MCP Components

An MCP implementation can expose:

- Resources
- Tools
- Prompts


## Resources

Resources provide contextual information that AI systems can access.

Examples:

- Documents
- Database records
- Files
- Application data


## Tools

Tools allow AI agents to perform actions.

Examples:

- Query a database
- Call an API
- Execute a business operation


## Agentic Web Relevance

MCP improves AI agent interaction by providing:

- Discoverable capabilities
- Structured tool definitions
- Controlled access to external systems
- Standard communication between agents and applications


## Assessment Criteria

A website or service designed for AI agents should consider:

- Providing MCP endpoints
- Exposing documented tools
- Describing available resources
- Defining tool inputs and outputs


## Recommendation Example

If MCP capabilities are missing:

Recommendation:
Expose MCP-compatible tools and resources to make the service more accessible and actionable for AI agents.
