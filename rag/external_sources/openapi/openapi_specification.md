# OpenAPI Specification

Source:
OpenAPI Initiative - Official Specification

Reference:
https://spec.openapis.org/oas/latest.html


## Overview

OpenAPI Specification (OAS) defines a standard, language-agnostic interface for describing HTTP APIs.

An OpenAPI document allows humans and machines to understand the capabilities of an API without accessing its source code.


## API Description

A valid OpenAPI document describes:

- Available endpoints
- HTTP methods
- Parameters
- Request bodies
- Response formats
- Authentication mechanisms
- Data schemas


## Machine Readability

OpenAPI specifications improve API discoverability and allow automated tools and AI agents to understand and interact with services.


## Agentic Web Relevance

For AI agents, an OpenAPI specification provides structured information about available actions.

Agents can use this information to:

- Discover available operations
- Understand required parameters
- Generate valid API requests
- Automate interactions safely


## Assessment Criteria

A website exposing APIs should provide:

- A public OpenAPI specification
- Clear endpoint documentation
- Defined request and response schemas
- Authentication information when required


## Recommendation Example

If no OpenAPI specification is detected:

Recommendation:
Expose an OpenAPI document describing available APIs to improve machine and agent accessibility.
